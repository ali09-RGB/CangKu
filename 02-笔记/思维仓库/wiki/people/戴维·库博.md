# 戴维·库博（David Kolb）

管理学学者。讲稿称他提出：**学习的本质是「行动—反思—理论—应用」的闭环。**

## 在本库中的位置

这个闭环是 [复盘](../concepts/复盘.md) 的理论底座，也是 [边干边学](../concepts/边干边学.md) 的方法依据：先干 → 遇到问题 → 查书找方法 → 把学到的用回来。

讲稿用它对照"普通人的顺序"：先理论 → 越学越怕 → 拖 → 勉强行动 → 发现和学的不一样 → 怀疑 → 放弃。

## 待验证

- 讲稿给出的是**四词简化版**（行动—反思—理论—应用）；体验学习循环的常见表述是"具体经验—反思观察—抽象概念—主动实验"。两者不完全一致，**未考证**
- 讲稿称其为"管理学大师"，未给出处；ASR 原文为"戴维库博"，讲稿校正为"戴维·库博（David Kolb，体验学习循环）"
- 只有一篇 source 提到，且该 source 是 ASR 转写稿
