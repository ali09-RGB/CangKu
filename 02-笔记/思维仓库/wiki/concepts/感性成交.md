# 感性成交

**成交的那一瞬间是感性的，而你提炼购买理由的动作是理性的。你拿理性去对感性，怎么可能有用。**

两篇相隔很远、主题无关的讲稿给出了同一判据——这是本批材料里最有价值的交叉印证。

## 两处的说法

| 来源 | 原话要义 |
| --- | --- |
| [超级获客](../../raw/articles/超级获客.md) | 理性提炼不出购买理由；要塑造感觉 |
| [七宗罪与人性营销](../../raw/articles/七宗罪与人性营销.md) | 理性是成交的天敌 |

## 具体做法：塑造感觉，而不是堆理由

[超级获客](../../raw/articles/超级获客.md) 要求把视频当成**一对一销售**，去抓成交的那一瞬间：

- 强欲望的客户 → 给他**捷径感**（例如"二十四个小时帮你搭起闭环"）
- 强恐慌的客户 → 给他**安全感**（说话温柔、强调保护隐私、显得靠谱、没有攻击性）

[七宗罪与人性营销](../../raw/articles/七宗罪与人性营销.md) 则从情绪侧给了同一件事的另一半：
**先把观众从理性里拽出来**。

> 嫉妒从来不来自远方。最不希望你过得好的人，很可能就是每天跟你勾肩搭背的人。

同理蜗的例子：直接说功能"有用"，但顾客随即进入比价的理性模式；改成"大长腿夏天出行必备"
——让顾客想到的是腿、是闺蜜、是短裤——嫉妒把人拉回感性。

## 配套的恶魔流程（两篇交汇处）

1. 用 [时机获客](时机获客.md) 找到此刻需求强度最高的人
2. 用 [精准人群](精准人群.md) 的标准筛出沉没成本已经压下去的人
3. 用 [七宗罪营销](七宗罪营销.md) 里的情绪开关把他从理性里拽出来
4. 塑造成交感：给捷径感或安全感

## 该怎么用这一页

这一页描述的是**操纵技术**，不是说服技术。库里的数据来源（两篇口播稿）全部以"提高主播转化"为目的，
无一讨论边界。如果要把它用在自己的产品上，先想清楚你要对方的什么、他事后会不会后悔。
