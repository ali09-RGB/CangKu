# 频率

讲稿重新定义了"吸引力法则"：核心不是心想事成，而是**频率**。

> 你人生所有的一切，都是由你的频率自然生发出来的。你是谁，你就能有谁的结果；而不是你想成为谁，你就能有谁的结果。

**本页整篇置信度标为 `unverified`**：这是讲稿的一家之言，包裹在玄学表述里，无研究出处，且 source 本身是 ASR 转写稿、含大量存疑处。下面记录的是"讲稿怎么说"。

## 频率 = 存在状态 = 潜意识

讲稿说，要用一个词代表"你是谁"，这个词就是频率；它**就是你的存在状态，就是你的潜意识**。

推论：只要你还在喘气，频率就一直在起作用。所以匮乏的人连做梦都在抓取、担忧、害怕。

## 作用回路

频率 → 时刻状态 → 行为 → 结果 → 反过来强化频率。

## 怎么量：看注意力

按 [注意力纯度](注意力纯度.md)：注意力越稳定越纯粹，频率越高。
砍柴即砍柴 = 高频；砍柴时想着挑水 = 低频。

**高频吸引高频，低频吸引低频**（共振）。讲稿用它解释"钱流向不缺钱的人，爱流向不缺爱的人"。

## 一个重要警告

讲稿自己强调：**没搞懂频率之前，不要随便用吸引力法则。** 因为你想象自己有钱的时候，其实在告诉自己"我现在没钱"，反而强化穷人频率。

→ 这是本页最反常识、也最值得记住的一条：**"想要"本身会暴露"没有"。**

## 匮乏是怎么来的

讲稿用"不被感恩的父母"做例子：他们对孩子的好本质是**索取**，因为自身极度匮乏 → 强烈抓取 → 想用微小付出换巨大回报 → 注意力永远不在当下、被未来拉扯 → 低频。
