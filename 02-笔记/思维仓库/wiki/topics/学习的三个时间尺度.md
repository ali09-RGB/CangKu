# 学习的三个时间尺度

**本页是跨三种改变的综合页，属 LLM 综合（inferred），不是讲稿原文的逐字陈述。** 讲稿分述了化学、结构、功能三种改变，但未把它们放在同一条轴上比较；下面的表格与"阈值"提法是编译时的整理。

## 2026-10-22 补：第二篇 source 独立给出了同一条轴

《三遍以内都是娱乐》与《大脑可塑性原理》**内容毫不相干**（一篇讲学习法，一篇讲脑科学），却给出了可以对齐的结论：

| 本页的层次 | 《三遍以内》的说法 |
| --- | --- |
| [化学性改变](../concepts/化学性改变.md)（短时） | 三遍以内 = 刷新鲜感，考完就忘 |
| [结构性改变](../concepts/结构性改变.md)（长期） | 第四到第七遍，开始有新发现、能结合实践 |
| 内化完成 | 第七遍"刻进 DNA"；另一案例读十二遍，第八遍后才成本能 |

两处**独立吻合**，且《三遍以内》补上了本页原先缺的一环：**结构层不是到点就完成，而是从第四遍开始才逐步出现**。见 [深度重复](../concepts/深度重复.md)。

⚠️ 仍标 `inferred`：两篇都是 ASR 转写稿、都无研究出处，"独立吻合"也可能是同一套流行说法的不同包装。是否升 `verified` 由人决定。

## 一条轴

| 层次 | 输入 | 留存 | 多久见效 |
| --- | --- | --- | --- |
| [化学性改变](../concepts/化学性改变.md) | 单次学习 | 短时记忆 | 立刻，当天有效，考完即忘 |
| [结构性改变](../concepts/结构性改变.md) | 反复、长期 | 长期记忆 | 讲稿举例：三十天到十年不等 |
| [功能性改变](../concepts/功能性改变.md) | 长期专项训练 | 该脑区能力增强 | 未给出 |

## 怎么用这张表判断

做完一次练习，问一句：**这次落在哪一层？**

- 只做一次 → 只到化学层，会衰减
- 想"再也忘不掉" → 必须跨过结构层，代价是反复与时间
- 想把某项能力练到超过常人 → 是功能层，代价是长期专项训练

## 推论（inferred）

1. **遗忘不等于白学**：考完就忘说明只到化学层，是投入量的问题，不是能力问题
2. **阈值未量化**：讲稿只说改变速度因人而异、且分领域，没有给"多久算长期"的标准
   → 实践上只能靠自己记录：某项练多久之后开始"忘不掉"
3. **顺序不可逆**：化学层是结构层的前置，跳过重复不可能直接到结构层
