# 习惯与成瘾

[大脑可塑性](../concepts/大脑可塑性.md) 的**负面一侧**：可塑性是中性的，它记住好习惯，也记住坏习惯；它因为训练而增强，也因为荒废而退化。

## 坏习惯为什么难改

大脑结构已经**记住了那种行为模式**。讲稿举的是抽烟、喝酒、赌博。

**机制解释（讲稿给出，无出处）**：大脑一旦得到某种**快速获得多巴胺**的体验，就很难放弃这种模式——这就是成瘾行为的由来。

→ 出路只有一个方向：**通过其他方式获取多巴胺**，而这个过程"对你来说可能是非常痛苦的"。

## 反向：停止好习惯也会改变大脑

如果有每天读书的习惯，因为出去玩而中断了一阵，大脑也会慢慢"变笨"。

**不进则退，不存在停留**：你不想着让它变聪明，它就会变笨，不存在"我的智商维持住了"这个选项。

## 2026-10-22 补：还有一种"学习瘾"

《三遍以内都是娱乐》给了一个本页原先没有的例子——**成瘾的对象可以就是学习本身**：

不断买新课、找新方法、收藏新教程，把**收集**当成学习。讲稿的判断是：

> 你把这个过程当成了学习，但本质上你只是在喂养大脑的多巴胺成瘾。

特征与抽烟赌博同构：渴求新鲜刺激、没有及时反馈就换目标、越换越空。
→ 解毒剂不是意志力，是把同一份材料重复到越过第三遍，见 [深度重复](../concepts/深度重复.md)。

## 与正面可塑性的对照

| | 正面 | 负面 |
| --- | --- | --- |
| 输入 | 长期学习、训练 | 坏习惯、快速多巴胺 |
| 落点 | [结构性改变](../concepts/结构性改变.md) / [功能性改变](../concepts/功能性改变.md) | 同样的结构记忆 |
| 可逆性 | 需要长期投入 | 需要痛苦的替代来源 |

两者共用同一套机制，所以**方法也是同一套**：见 [行为塑造大脑](行为塑造大脑.md) 的"强迫成习惯，习惯成自然"。

## 待验证

- 多巴胺机制是讲稿的解释性说法，**未给出处**，标为解释而非事实
- "出去玩了一阵"的时长、"慢慢变笨"的速率均无量化
