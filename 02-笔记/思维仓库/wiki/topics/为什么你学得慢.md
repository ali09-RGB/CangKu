# 为什么你学得慢

**本页是跨两篇 source 的综合（inferred）**，两篇独立讲了各自的诊断，下面把它们对齐成一张表。讲稿本身没有做过这个合并。

## 两篇给出的诊断

|       | 《三遍以内都是娱乐》   | 《高效学习三要素》         |
| ----- | ------------ | ----------------- |
| 病根    | 停在第三遍就换材料    | 学习顺序反了：先理论后行动     |
| 表现    | 收藏夹、书架堆满没看完的 | 越学越怕、越怕越拖         |
| 大脑在干嘛 | 刷新鲜感，喂多巴胺    | 跟自己的大脑对着干         |
| 处方    | 同一材料过七遍      | 边干边学 + 拆最小单元 + 复盘 |

## 合并后的三个卡点

1. **卡在次数**：材料换了够多，没有一份过三遍 → 见 [深度重复](../concepts/深度重复.md)
2. **卡在顺序**：想先准备好再动手 → 见 [边干边学](../concepts/边干边学.md)、[目标拆解](../concepts/目标拆解.md)
3. **卡在收尾**：干完不回头看，下次犯同样的错 → 见 [复盘](../concepts/复盘.md)

## 两条共性

- **都是反人性的**：重复枯燥、动手丢脸、复盘无聊。讲稿两篇独立都点了"真正的学习是反人性的""全程痛苦内耗"
- **判据都是行为**：不是"我懂了没有"，而是"我的行为变了没有"。两篇都把这条当成唯一硬标准

## 一条推论（inferred）

"学得慢"和"学不会"是两回事。上述三个卡点都属于**方法层**，两篇讲稿都没把它归因于能力或天赋；其中一篇还明确说"不是因为笨，问题全在方法上"。
→ 若你长期觉得学得慢，先查这三个卡点，而不是怀疑脑子。这与 [大脑可塑性](../concepts/大脑可塑性.md) 的"可塑性人人都有、只是快慢不同"是一致的。
