# S071 · 塑品四段对称：痛点要配坏处，卖点要配好处

> **等级 B（方法论）｜ 发布 2026-09-13 ｜ 状态：有效**
>
> 到期日 **2027-09-13**。这是表达结构，不依赖平台规则。

> **一句话价值**：塑品只讲一半必然失效——
> **只讲痛点不讲坏处，痛点留不住人；只讲卖点不讲好处，卖点没有分享感。**
> 完整结构是四段：**痛点 → 坏处 → 卖点 → 好处**，而且它适用于任何东西。

## 一、两条「只说一半」的诊断

> 「如果只讲痛点不讲坏处，**这个痛点是不留人的**。
> 如果只讲卖点不讲好处，**那这个卖点没有什么分享感**。」

这两句是同一个毛病的两面：**只说「是什么」，不说「所以呢」。**

| 缺哪一半 | 后果 | 为什么 |
|---|---|---|
| 有痛点，没坏处 | 痛点留不住人 | 观众知道「我确实这样」，但没感到「这样很糟」，不足以为此停下 |
| 有卖点，没好处 | 卖点不传播 | 观众知道「它有什么」，但不知道「对我有什么用」，无从转述 |

**「坏处」和「好处」都是把事实翻译成后果**。这一步不做，前面讲的都只是描述。

## 二、例子一：卤肉饭（完整拆解）

| 段 | 原话 |
|---|---|
| **痛点** | 「你们有没有跟我一样特别爱吃卤肉饭的？但大多数卤肉饭我都吃不完一整碗，因为它真的**肥肉太多了**。」 |
| **坏处** | 「那种肥肉很多的，我**总是点一碗剩半碗**，实在是吃不动，**太腻了**。」 |
| **卖点** | 「但是这个卤肉饭真的不一样……它里面所有的肉是**肥瘦相间的**，加上里面加的一点点自己**秘制的小酱料**。」 |
| **好处** | 「**一点都不腻**，所以我一整碗都把它吃掉，**一点都不浪费**。关键是味道真的绝了。」 |

注意坏处和好处是**一一对应**的：

```
坏处「剩半碗、太腻」  ←→  好处「整碗吃完、不腻、不浪费」
```

**这种对应关系不是巧合，是结构要求**：坏处挖的坑，好处要正好填上。
坑挖在东、填在西，观众就觉得「你说的不是你解决的问题」。

## 三、例子二：奶茶（换品类验证）

| 段 | 原话 |
|---|---|
| **痛点** | 「过了三个月之后，你们是不是觉得**不太敢喝奶茶了**？过了下午两点就不敢喝了。」 |
| **坏处** | 「下午两点之后喝完，**一晚上睡不着**。」 |
| **卖点** | 「因为它里面是**不含任何一点茶的**，就是荔枝加柠檬加奶的味道……关键它**不是做得很甜**。」 |
| **好处** | 「你喝完**并不会睡不着**，关键**口感真的非常好**。」 |

同样是「坏处↔好处」对应：**睡不着 ↔ 不会睡不着**。

两个例子一荤一素（饭 / 饮品），说明这套结构不挑品类——
他自己也强调：

> 「生活里面的任何一个东西，你都可以按照**痛点、坏处、卖点、好处**的顺序去塑品。」

## 四、这套结构的附带好处

> 「不仅能够留人，关键**你讲话的时候有框架**，不会（想到）哪里说到哪里。」

这是容易被低估的一点：**四段结构不只是话术，还是「不跑偏」的护栏**。
直播里最容易发生的不是话术不好，是讲着讲着散了——
有了「现在该讲坏处」这个锚，主播就不会在卖点上无限展开。

## 五、和另外几套框架的关系

库里已经有三套相邻的塑品框架，容易混，这里对齐一下：

| 框架 | 结构 | 强项 | 出处 |
|---|---|---|---|
| **本篇：四段对称** | 痛点 → 坏处 → 卖点 → 好处 | **每一段都要落到后果**，最抗「讲了像没讲」 | S071 |
| 拉停留四步 | 痛点 → 场景 → 方案 → 期待 | 面向**刚进来的人**，目的在于留人 | S050 |
| 平播密度×深度 | 密度（理由数量）× 深度（价值论证） | 面向**已经在听的人**，目的在于撑住时长 | S044 |
| 高客单三层 | 私享场景 → 自我共情 → 长期收益 | 面向**高价商品**，目的在于给「许可」 | S068 |

四套不是互相替代，是**用在不同的位置**：

```
新人刚进来  → S050（留人）
留下来听    → S071（把卖点讲成后果）
要撑时长    → S044（密度×深度）
卖贵的东西  → S068（换语言方向）
```
