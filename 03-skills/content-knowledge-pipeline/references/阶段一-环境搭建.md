# 阶段一 · 环境搭建

目标：在一台干净的 Windows 机器上，从零到**跑通一条链接的完整提取**。

验收标准只有一条：给一条分享链接，能产出「元数据 + 音频 + 转写文本」的素材包。达不到就不算搭好，不要急着进阶段二。

## 组件清单

| 组件 | 装在哪 | 为什么 |
|---|---|---|
| Python 3.13+ | 宿主 | 全部脚本 |
| Chromium（Playwright 自带）或 Chrome/Edge | 宿主 | CDP 截流必须有真浏览器 |
| Node.js | 宿主 | CDP 通信（`sniff.js`） |
| `faster-whisper` + 模型 | 宿主 | 语音转写，CPU 可跑 |
| SQLite | 宿主 | 中转库，单文件，无需服务 |
| Obsidian vault | 宿主 | 最终知识库 |
| n8n | 容器（可选） | 只做定时调度 |

**关键原则：凡是依赖宿主浏览器或大模型的，都不进容器。** 容器里没有浏览器，模型缓存也不该随容器重建而丢失。

## 步骤

### 1. Python 依赖

```bash
python -m pip install playwright faster-whisper av opencc-python-reimplemented
python -m playwright install chromium
```

`av` 是 PyAV，用来解容器里的音轨；`opencc` 做繁简统一。两者都不能省——ASR 有约 20% 概率整篇输出繁体，不做转换后面的术语规则一条都命中不了。

### 2. 模型（国内网络）

```bash
set HF_ENDPOINT=https://hf-mirror.com     # Git Bash: export HF_ENDPOINT=...
```

首次转写会自动下载 `small` 模型（约 500MB）。不设镜像大概率卡住且没有明确报错，表现成「一直没反应」。

### 3. 数据库

SQLite 单文件，首次运行脚本自动建表。主要几张：

| 表 | 作用 |
|---|---|
| `candidate` | 采集回的候选池（判定结果 + 审批状态） |
| `sample` | 已收录的样本 |
| `asset` | 素材文件登记 |
| `report` | 报告登记 |
| `feedback` | 审批反馈，负样本来源 |

### 4. 知识库目录

```
<vault>/
├── 00-首页·知识地图.md
├── 10-视频报告/<主题>/
├── 20-方法论索引/
├── 30-术语表/
└── 90-归档/
```

路径写进 `domain.json` 的 `vault.path`，或用环境变量 `KNOWLEDGE_VAULT` 覆盖（优先级更高）。

### 5. 宿主 HTTP 服务（只有用 n8n 才需要）

```bash
python service.py      # FastAPI，监听 8770
```

n8n 容器通过 `http://host.docker.internal:8770` 调它。

## 必须在开始前知道的四件事

**一、必须用有头模式。**
无头浏览器访问内容平台会被「验证码中间页」拦死，不是偶发，是稳定复现。不要试图绕过，直接用有头。

**二、登录判定只认会话 cookie。**
不要用 `csrf_token` 之类的字段判登录——匿名访客也有。只认 `sessionid` 非空，判完截图肉眼确认。

**三、n8n 的 Execute Command 节点没有 Python。**
「在 n8n 里直接跑 `python extract.py`」这条路走不通。所有重活放宿主服务，n8n 只发 HTTP 请求。

**四、容器不要挂载项目目录。**
n8n 只挂自己的数据目录。挂载越少，重建时越不会误删数据。所有文件读写都在宿主完成。

> Docker 引擎起不来时先看是不是虚拟化被安全策略拦了（某些环境下 `wsl.exe` 在禁用名单里）。这不是代码问题，需要人工启动 Docker Desktop。

## 验收

```bash
cd "$WS/工具"
python extract.py "https://www.douyin.com/video/<id>"
ls ../素材包/<id>/     # 应有 meta.json + 音频 + transcript.txt
```

能出这三个文件，阶段一结束。出不来，先解决它，不要进阶段二——阶段二的所有判断都建立在「能拿到内容」之上。
