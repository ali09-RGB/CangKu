# 知识库副本

这个仓库是把本地笔记导出的一份**只读副本**，用途是让不同设备、不同 AI 共用同一份内容。

## 给 AI 用的入口

- `llms.txt` —— 带分类的索引，先读这个
- `llms-full.txt` —— 全部内容合订（约 100 万字），多数模型读不完，按需取用

## 内容

- **直播带货知识库** —— 直播带货运营知识，36 篇视频报告 + 首页地图
- **思维仓库** —— 营销、人性、商业思维的读书与拆解笔记
- **技能** —— 内容→知识库流水线技能（四阶段可复用的工作流定义）
- **流水线建设** —— 采集筛选、提取转写、归档的设计决策与踩坑记录

## 说明

- 共 138 篇 Markdown。
- 由脚本从本地导出，**手工改动会在下次导出时被覆盖**。
- 个人数据一律未纳入。

## 维护

本地改完重新跑一次导出脚本，提交即可。
