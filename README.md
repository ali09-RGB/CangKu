# 知识库副本

这个仓库是把本地笔记导出的一份**只读副本**，用途是让不同设备、不同 AI 共用同一份内容。

## 给 AI 用的入口

**先给它 `llms.txt`** —— 带分类的索引，里面有全部单篇地址。

想一次性投喂一整个主题，用下面任一合订本（按需取一份，不要全给）：

- `llms-live-commerce.txt` —— 直播带货，77 篇 / 约 30.7 万字
- `llms-method.txt` —— 流水线方法，6 篇 / 约 8.9 万字
- `llms-skill.txt` —— 技能，6 篇 / 约 1.7 万字
- `llms-thinking-raw.txt` —— 思维笔记 · 原文，25 篇 / 约 11.5 万字
- `llms-thinking-wiki.txt` —— 思维笔记 · 整理，63 篇 / 约 5.4 万字

## 内容

- **直播带货知识库** —— 直播带货运营知识，按主题分目录的视频报告 + 首页地图
- **思维仓库** —— 营销、人性、商业思维的读书与拆解笔记
- **技能** —— 内容→知识库流水线技能（四阶段可复用的工作流定义）
- **流水线建设** —— 采集筛选、提取转写、归档的设计决策与踩坑记录

## 说明

- 共 177 篇 Markdown。
- 由脚本从本地导出，**手工改动会在下次导出时被覆盖**。
- 个人数据一律未纳入。

## 维护
