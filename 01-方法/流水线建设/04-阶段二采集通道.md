## 二、两条通道的真实状态

| 通道 | 接口 | 状态 | 说明 |
|---|---|---|---|
| **搜索流** | `/aweme/v1/web/general/search/single/` | ✅ 已跑通 | 关键词驱动，确定性高，**当前主力** |

### 搜索流（主力通道）

- 数据结构：`{data: [{type, aweme_info, ...}]}`，取 `data[].aweme_info`

要让它可用，必须先"养号"：让小号连续几天只刷直播带货内容。
在养号完成前，**搜索流是唯一可靠来源**。

## 三、四个硬结论（都踩过坑）

### 1. 无头模式彻底不可用

无头 Chrome 打开抖音，返回标题是**「验证码中间页」**，cookie 里只有反爬标记，
一个视频都拿不到。有头模式立刻正常（标题变「抖音精选电脑版」）。

→ 这个工具**不能后台静默跑，必须有窗口**。想做成定时任务，得允许弹窗。

### 2. 抓 DOM 这条路是死的

页面上 `a[href*="/video/"]` 数量是 **0**——卡片全靠 JS 点击事件，没有真实链接。
必须抓接口 JSON。

### 3. 登录判定不能用 `passport_csrf_token`

曾误报过一次：cookie 里 `passport_csrf_token` 存在（匿名访客也有），
但 `sessionid` 为空，脚本以为已登录，结果搜索页仍弹「登录后即可搜索」，
一条数据拿不到。

→ 唯一可靠标志是 `sessionid` / `sessionid_ss`。

### 4. 搜索页会「间歇性不发起请求」

连续 goto 不同关键词时，有时整页 **0 次** `general/search/single` 调用，
表现就是「抓到 0 条」。同一关键词单独重跑又正常——是 SPA 加载竞态，不是无结果。

→ 已加重试：先回 `about:blank` 强制全新加载；无响应则加时间戳参数重试，最多 2 次。
实测 12 个关键词中曾失败 3 个，加重试后全部成功。

## 四、判定器（classify.py）v2

### 为什么重构

v1 用「强词凑分 ≥ 6」放行。在真实搜索流上暴露大量**漏判**：

- 「一条视频九分钟教会你**直播复盘**到底看哪些数据」→ 漏判
- 「**直播间留人**四个关键」→ 漏判
- 「天才运营的逆向**选品**逻辑」→ 漏判
- 「新手直播千万不要盲目**拉时长**」→ 漏判

原因：这些核心术语根本没进词表，单强词只有 3 分 + 标签 2 分 = 5 分，卡在阈值下。

### v2 规则：两级放行

| 级别 | 作用 | 举例 |
|---|---|---|
| **核心词 CORE** | 领域定义性术语，**命中一个即通过** | 直播带货 / 憋单 / 千川 / 直播复盘 / 拉时长 / 选品 |
| **支撑词 SUPPORT** | 含义宽泛，**需命中 ≥2 个** | 直播间 / 开播 / 话术 / 复盘 / 留人 / 流量 |
| **负词 NEGATIVE** | **一票否决** | 娱乐直播 / 游戏直播 / 才艺主播 / 美食教程 |

分数只用于排序展示，不再参与放行——避免"凑分"这种脆弱机制。

### 娱乐直播必须拒

新增负词表专门挡这一类：`娱乐直播 / 娱乐主播 / 才艺主播 / 游戏直播 / 秀场 / 陪玩 / 聊天主播`。
它们是另一套知识体系，大量使用「开播」「留人」「话术」，不挡会被大量误捞。

### 自测结果

```
真样本命中     7 / 8      （唯一漏判：标题零信号的"19-199，四马拖车"）
主题准确       6 / 6
边界 + 回归   20 / 20     （含 6 条真实漏判回归 + 2 条娱乐直播必须拒）
合计正确率    27 / 28 = 96%
```

### 主题归类并列处理

`TOPICS` 各主题词数相同时，原先直接 `max()` 按字典顺序取，导致误归类：
「中控控单节奏…短视频追投不能停」因命中泛词「短视频」被归到**内容获客**，
实际是投放/流量主题。

已加 `TOPIC_PRIORITY` 做并列裁决，顺序为
**成交方法 → 流量节奏 → 付费投放 → 话术情绪 → 算法机制 → 内容获客**（越前越具体）。
generic 的「内容获客」放最后，避免它抢走具体主题。

### 关于那个 1 条漏判

阿瑞讲「19-199，四马拖车，了解下」——标题、标签、作者名**全部零信号**，
只有看内容才知道讲的是千川投放。

这是轻量初筛的**固有天花板**，不是 bug。处理方式：
在阶段二放宽为"高分的待定项也进候选池"，或等阶段三提取后再归类。

## 第 2 批采集（2026-11-12 晚 · 已完成）

### 为什么要换关键词

第一批 12 个词采完 274 条后，回头看已采内容的标签分布：`#直播带货` 86 次、
`#主播培训` 51 次、`#直播运营` 46 次——**说明这批词彼此高度重叠，采回来的是同一类内容**。
继续用它们只会重复，不会扩大覆盖面。

所以第二批换了 22 个「第一批完全没覆盖的细分术语」，按七个主题的缺口填空，
写入 `工具/keywords-batch2.txt`，用新加的 `--kwfile` 参数单独跑，
不与旧表混用（混用只会把旧内容再搜一遍）。

### 结果

| 指标 | 数值 |
|---|---|
| 关键词 | 21 个（`直播切片` 整词废弃，见下） |
| 耗时 | 9 分 23 秒 |
| 抓到 | 620 条 |
| 新入库 | 542 条 |
| 判定命中 | 471 条 |
| 候选池累计 | **816 条**（命中 630） |

两个关键词触发了重试（`开场话术`、`进入率`，都是「接口调用 0 次」的老毛病），
第 1 次重试均成功——SPA 加载竞态的重试机制有效。

### 一条重要规律：命中率由「关键词专业度」决定，不是判定器水平

各关键词命中率差异巨大，且排列完全有序：

| 关键词 | 命中率 | 关键词 | 命中率 |
|---|---|---|---|
| 随心推 / 全域推广 / 素材追投 / 五维四率 | **100%** | 直播间搭建 | 36% |
| 开价 | 97% | 投产比 | 18% |
| 逼单 | 96% | **直播切片** | **0%** |
| 成交密度 | 94% | 人设 | 41% |

**规律：专业术语词命中率 80–100%，泛词 0–60%。**

抽查验证了这个判断，两个低分词都拒得对：

- **`直播切片` 0%** —— 搜出来是「怎么剪辑」「切片授权」「AI 自动剪辑」，
  那是**剪辑技能**，不是直播带货运营知识。整词作废，不要再用。
- **`投产比` 18%** —— 被拒的是拼多多/淘宝的投产比算法（「拼多多运营」「保本投产比怎么算」），
  跟抖音直播带货不是一套体系。命中的那 22% 是千川 ROI。

**结论（已写进 D-23）：关键词表只放专业术语，不放泛词。**
泛词不会提高召回，只会灌进一批其他领域的内容让判定器挡掉，
白耗采集配额、拉低信噪比。「人设」「痛点」「直播间搭建」下次可以剔掉。

### 同时抓到一条误收

`投产比` 搜出来的「拼多多开店卡高投产+切车玩法撬动自然流量」被判为命中，
但它是**拼多多**玩法，不是抖音直播带货。

**这是判定器的一个真实盲区：它不区分平台。** 目前负词表里没有「拼多多/淘宝/天猫」。
要不要把「跨平台电商内容」判为非目标，取决于王总的偏好——如果他做的平台不限于抖音，
这类内容其实有价值。**列为待定项 D-24，不擅自决定。**

### 池子现状

816 条中未审的命中 **619 条**，主题分布：
付费投放 143 · 待定 128 · 成交方法 104 · 话术情绪 96 · 数据复盘 68 · 流量节奏 50 ·
内容获客 19 · 算法机制 11

### ⛔ 两个新问题，都是「架构性的」，不是调参能修

**问题一：加了新主题，忘了加放行词 → 命中率 0%**

「价格带」0% 看着像"内容不相关"，实际是**判定器根本不认识这个词**。

原因是判定器有两套词表，职责不同：
- `CORE` / `SUPPORT` → 决定**放不放行**
- `TOPICS` → 决定**归到哪一类**

D-27 只加了 `TOPICS`，没加 `CORE`/`SUPPORT`，所以这些词只被归类、从不被放行。
已补进 `SUPPORT`（不补 `CORE`，因为这些词单独出现歧义大，
「赛道」可能是职业赛道，必须与另一个支撑词同现）。

**问题二：`pick.py` 里硬编码主题列表 → 新主题拿不到缺口加权**

`gap` 里写死了七个旧主题名，新增的「选品排品」虽然池里有 119 条、
库里 0 篇（缺口最大），却拿不到一分加成，**一条都进不了清单**。
已改成从 `TOPICS` 动态取。

> **这两条是同一个病根**：主题定义分散在多处，加一处忘一处。
> 判定器、收口脚本、归档脚本各自维护一份主题清单，迟早会打架。
> 现在的做法是尽量从单一来源（`TOPICS`）派生，但还没完全消除。

### 问题三：高命中率 ≠ 高质量

「直播中控」命中率 87%，但命中的里面有「00 后中控不上班只兼职的一天」
「盘点电商中控捧哏名场面」「这玩应不叫中控叫演员」——**是段子，不是方法**。

这类内容大量使用「中控」「主播」「运营」这些词，任何词表都挡不住。
已加一组娱乐负词：`名场面/搞笑/捧哏/belike/段子/沙雕/整活/精神状态`。
实测剔除 5 条，全部判断正确。

**D-23 需要修正**：之前说「命中率由关键词专业度决定」，
现在要补一句——**专业词也可能带来娱乐化内容，命中率是必要条件，不是充分条件。**

### 一个需要王总判断的边界

新收的 29 条里有不少是**短视频运营**而非直播运营：
「播放量卡在 500」「怎么找对标爆款视频破播放量」「提高账号权重」。

它们和直播带货有关（短视频能引流），但驱动力是另一套（完播率、涨粉）。
是否算命中，取决于王总要不要「短视频引流」这条线。**暂不擅自决定。**
